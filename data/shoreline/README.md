GSHHG 2.3.7, 15 June 2017. Shoreline data by Paul Wessel, Walter H. F. Smith and the GSHHG contributors.

Source: https://github.com/chartcatalogs/gshhg/releases/tag/v2.3.7 (OpenCPN-preprocessed polygon files); https://www.soest.hawaii.edu/pwessel/gshhg/

The original polygon bytes are unchanged; gzip recompression is deterministic. Plugin packages bundle Crude, Low and Intermediate for offline installation. High and Full are available separately through Configuration / Advanced / Shoreline data (also View / Shoreline data) from two versioned HTTPS mirrors, with both archive and uncompressed SHA-256 verification. Existing High/Full installations remain usable. The reader loads the selected dataset; it does not simplify Full at runtime. See manifest.json for payload sizes and SHA-256.
