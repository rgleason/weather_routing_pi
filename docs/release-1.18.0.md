# Weather Routing / xWeatherRouting 1.18.0

This release aligns the plugin's user-facing version with the current three-engine
release. It includes Quick (Hardened Original), Standard and Professional, plus
the first-use defaults, independent engine settings and shoreline/data safety
changes described in [the 1.17.4 release notes](release-1.17.4.md).

Alpha packages are built separately for each supported desktop platform. Each
tarball includes a root-level `metadata.xml` so it can be imported directly
into OpenCPN. Android remains excluded. The Windows package is for 32-bit
OpenCPN; a 64-bit Windows package has not been built.

The package metadata uses OpenCPN's four-component version `1.18.0.0` for the
release named 1.18.0.
