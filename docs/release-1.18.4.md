# Weather Routing / xWeatherRouting 1.18.4

The Advanced settings now reflow the GRIB cache, shoreline and chart depth
explanations when the dialog is resized. The shoreline explanation sits beside
the Shoreline data button when space permits and moves below it in a narrow
window. The minimum-depth explanation now appears directly below its control.
All controls and safety information remain available, and the page can still
scroll on smaller displays.

This release changes the settings layout only. Routing behaviour and saved
configuration are unchanged.
