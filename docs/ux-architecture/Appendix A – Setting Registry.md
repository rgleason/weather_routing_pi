# A.1 Purpose

The Setting Registry is the authoritative catalog of all WeatherRouting settings.

Every setting shall have:

- Unique SettingId
- Single owner
- Defined default value
- Visibility rules
- Validation class
- Persistence scope
- Readiness impact
- Migration support

Every subsystem shall derive behavior from this registry.

```text
Setting Registry
        ↓

UI Visibility
Validation
Persistence
Migration
JSON Schemas
Documentation
Testing
```

---

# A.2 Registry Structure

```cpp
struct SettingDefinition
{
    SettingId id;

    wxString category;

    wxString function;

    wxString label;

    SettingType type;

    SettingValue defaultValue;

    Visibility beginner;
    Visibility intermediate;
    Visibility advanced;

    PersistenceScope persistence;

    ValidationClass validation;

    bool computeCritical;

    wxString owner;

    uint32_t introducedVersion;
};
```

# A.13 Registry Completion Criteria

Every setting in the registry must satisfy:

```text
SettingId
      ↓

Owner
      ↓

Default
      ↓

Visibility
      ↓

Validation
      ↓

Persistence
      ↓

Migration
```

Appendix A is considered complete when no user-visible setting exists outside the registry and every WeatherRouting configuration item can be traced through that chain.
