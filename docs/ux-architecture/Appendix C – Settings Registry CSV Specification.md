# C.1 Purpose

Appendix C defines the machine-readable representation of the entire WeatherRouting settings architecture.

The CSV registry serves as the authoritative metadata source for:

```text
SettingId Generation

SettingsRegistry.cpp

Visibility Rules

Validation Binding

Persistence Binding

Migration Support

JSON Schema Generation

Documentation Generation

Test Generation
```

All runtime configuration metadata shall be derivable from this registry.
