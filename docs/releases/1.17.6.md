# Weather Routing / xWeatherRouting 1.17.6

Standard OpenCPN land detection now uses a plugin-owned GSHHG shoreline reader
with bundled full-resolution 2.3.7 data. A missing host basemap no longer makes
an unchecked crossing appear to be clear water. No enhanced core is required.

* Full-resolution data is included in every plugin package and installs offline
  on first use. The unmodified upstream polygon bytes are pinned by SHA-256 and
  exact length; provenance, the data licence and a manifest accompany them.
* The reader checks segment intersections and land containment, including exact
  grid boundaries, corner touches, nested lakes/islands and the dateline.
  Traversal is symmetric. A shared, bounded tile cache avoids loading the whole
  164 MiB file into memory. The default cache limit is 64 MiB; full detail is
  retained when the cache evicts tiles.
* View > Shoreline data selects full or optional high resolution, verifies data,
  downloads/repairs it, restores the bundled full dataset, and adjusts the cache
  limit (16–256 MiB). The installed path can be selected and copied. Dataset
  release information opens the upstream release page; automatic acceptance of
  arbitrary new data is intentionally excluded from the verified-data contract.
* Downloads try two HTTPS release mirrors in order. Transport errors, timeouts
  and checksum failures try the next source; cancellation stops immediately.
  Both current mirrors are on GitHub, so they protect against a missing/broken
  repository asset, not a complete GitHub outage. Bundled full data still works
  offline. Downloads install a new generation only after successful validation;
  existing files and data pinned by route configurations are not overwritten.
* Start/destination positions on land are rejected explicitly. Missing or corrupt
  selected data fails closed. Read failures during computation stop the route
  with a shoreline diagnostic instead of continuing an unsuccessful land search.
* Existing chart-aware propagation, depth enforcement, prewarming and host
  fallback paths remain unchanged. GSHHG is not substituted for chart depths.
  Display basemap configuration is separate and is not changed by this plugin.
* Package checks validate the actual bundled file and its licence on Linux,
  Windows, macOS and Flatpak. macOS staging preserves nested data directories
  without making duplicate root-level copies of the shoreline archive.

## Validation

255 automated tests passed on native Linux and Debian 12. These include verified
installation from the actual bundled full dataset, geographic controls,
corruption, cancellation, mirror failover, bounded cache eviction, concurrent
reads and existing routing/chart-safety regressions. Both plugin identities and
Debian 12 packages were built and their actual payload checksums verified.

Stock OpenCPN 5.14 completed full- and high-resolution coastal routes and an
1884 NM ocean route with full resolution. The full Provincetown-to-Lizard
passage also completed with full-resolution land detection at 100% effort
(6-hour time step, 20-degree heading increment). The enhanced-core CM93 Vava'u control
produced exactly the same route as 1.17.5. Unsupported positive-depth requests
and absent selected data retain actionable failures. Disposable GUI checks cover
full/high selection, offline installation, live download, verification, saving,
menu spacing and enlarged fonts. Cross-platform build status and additional
qualification results are recorded with the release work; a successful build is
not a claim that every platform's GUI has been executed.
