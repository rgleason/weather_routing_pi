# Weather Routing / xWeatherRouting 1.17.3

This release fixes four defects reproduced while investigating the Debian
1.17.2 preview report. Both plugin identities contain the same routing fixes.

* **Chart settings take effect immediately.** Changing Check loaded charts or
  Require chart/depth checks stops calculations using the previous global
  policy and invalidates all stored route results, including unselected routes.
* **Chart validation uses the short longitude interval.** Equivalent positive
  and negative western longitudes no longer cause a nearly worldwide final-leg
  traversal. Date-line crossings are split for older host implementations;
  derived chart tiles and reported hit coordinates use canonical longitudes.
  Land, depth and missing-data rejection remain enabled.
* **GRIB coverage is checked before search.** The adapter reports the intersection
  of the departure frame's wind-component grids instead of unconditional global
  coverage. An uncovered endpoint produces a wind-forecast error before search
  states are generated. Explicit Climatology/deficient-data policies remain
  available. Frame bounds do not prove complete passage-time coverage: actual
  wind sampling still checks availability along the route.
* **Single-route headless limits include preparation.** Raw chart extraction
  checks cancellation/deadlines between tiles. One host tile extraction remains
  indivisible and may overrun the deadline; mutable chart access stays on the
  required host thread. Preparation time counts toward the monitor's limit.

## Validation

230 tests passed on native Linux and Debian 12, including western-longitude,
date-line, real obstacle/depth, coverage preflight and deadline regressions.
Both standard and xWeather plugin identities build on the laptop.

Tests using the unchanged 2026-09-11 Debian 12 preview core and a replacement
plugin reproduced the original controlled scenarios in isolated profiles:

* Covered synthetic GRIB route completes; uncovered destination fails in
  preflight; explicitly enabled Climatology fallback completes outside the GRIB.
* CM93 Vava'u (-18.62,-174.08) to (-18.62,-173.88) completes and passes final
  validation. The old final segment checked a false land crossing near South
  America for about 60 seconds; final validation now records 0 milliseconds.
* CM93 Pacific open-water (-20,-175) to (-20,-174.8) completes. A deliberately
  short preparation deadline returns a timeout without an outer process kill.
* Ordinary GUI launch, with no headless safety overrides: changing only the
  two safety checkboxes changes Complete to Not Computed. Recompute logs the
  newly enabled checks and rejects the no-loaded-chart control case. A second
  GUI test verifies that changing one selected route's global checkbox also
  invalidates an unselected completed route.

These tests cover the reproduced defects, not Quinton's exact unpublished
boat/GRIB/configuration. Intel GPU rendering, intermittent initial window size
and live native isochrone display are not changed by this release. No new core
ABI or core rebuild is required for these plugin fixes.
