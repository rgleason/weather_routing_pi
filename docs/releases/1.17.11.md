# Weather Routing 1.17.11 — compact shoreline package

Plugin packages now include GSHHG 2.3.7 Crude, Low and Intermediate shoreline
data. High and Full remain available through **Configuration / Advanced / Shoreline data...** (or **View / Shoreline data**), but are
downloaded separately when requested. The approved archives are mirrored by the
versioned `pob220/weather_routing_pi` GitHub release and `www.singe.media`.
The compact Advanced-tab button opens a manager with a one-action High-and-Full
installer as well as individual install, update and verification controls.
Both the compressed archive and its installed polygon data are checked against
the version and SHA-256 values built into the plugin. A failed or cancelled
download leaves the previously installed dataset intact. After installation,
the selected shoreline data works offline.

The manager's **Install / update selected data** button reports an already
verified 2.3.7 installation as current. It installs missing or damaged approved
data; it does not automatically accept an unqualified newer upstream dataset.
Future dataset versions require a plugin update which approves their format,
sizes and hashes. Previously installed High or Full data remains usable.

New Main routes default to Intermediate so a compact installation works offline.
Existing route and engine selections are preserved. A route requiring a missing
or damaged High/Full dataset fails explicitly rather than silently using a
coarser shoreline. Intermediate and lower levels can omit coastal features;
install High for more detailed coastal land checks, and do not treat GSHHG as a
navigational chart.
